# QuoteFix

QuoteFix is a Singapore condominium repair procurement and delivery workspace for four named roles: CM, MCST, Contractor and Admin. It connects observations, privacy-reviewed RFQs, sealed quotations, selection/approval, actual work, inspection, invoices, recorded external bank payments, support and audit records.

Product authority: [working memory](docs/PRODUCT_MEMORY.md), [open decisions](docs/OPEN_DECISIONS.md), and the user's latest direct instructions. Monetary and access rules are server-enforced. QuoteFix records external transfers; the interface does not send money. Drafts, file uploads and AI suggestions never constitute a consequential decision.

Current surface: the browser app at http://127.0.0.1:3000. The owner wants the supplied design system and focused sequential tasks, fewer simultaneous fields, concise copy and clear next actions. Existing data and checksum-protected SQL migrations must remain untouched. Native-device and unresolved policy work is separate.
